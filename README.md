# 🅿️ 離我最近 - 周邊即時車位看板 (Parking Availability Tracker)

專為駕駛設計的輕量化手機網頁小工具，透過手機 GPS 定位，自動搜尋周邊 1.5 公里內的公有停車場，並即時顯示剩餘車位數與滿位狀態。

---

## ✨ 主要功能

* **📍 周邊 1.5 公里搜尋**：自動計算 GPS 座標，列出周邊最近的公有停車場。
* **🟢 即時剩餘車位**：自動標示剩餘車位數量，車位充足顯示綠色標籤，滿位即時顯示紅燈警示。
* **📏 距離排序**：依據距離由近至遠排序，方便評估臨停選擇。
* **🔄 一鍵更新**：隨時點擊重新讀取最新車位資訊。

---

## 🛠️ 架構與技術

* **前端**：單頁 HTML5 / CSS3 / JavaScript（託管於 GitHub Pages）。
* **後端**：Google Apps Script (GAS) 部署為 Web App 伺服器端 API。
* **資料來源**：[TDX 運輸資料流通服務](https://tdx.transportdata.tw/) (Parking OffStreet API)。

---

## 🚨 注意事項與維護

1. **TDX Token 授權**：後端 GAS 專案需要在「專案設定 (齒輪) -> 腳本屬性」中設定 `TDX_CLIENT_ID` 與 `TDX_CLIENT_SECRET`。
2. **資料範圍**：即時車位數據取決於各縣市政府開放給 TDX 之公有停車場資料，部分私有停車場或未連線場次可能不在列表中。
